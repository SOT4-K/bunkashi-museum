# UI デザイン指針（frontend-design スキル準拠）

作成 2026-09-03（Hayato）。オーナー指示「frontend design を使って今っぽい UI に」。
手順: ①題材に根ざしたトークン設計 → ②「どの案件でも出てくる既定の見た目」になっていないか見直し → ③実装 → ④スクリーンショットで自己批評。
参照スキル本文: `~/.claude/plugins/marketplaces/claude-plugins-official/plugins/frontend-design/skills/frontend-design/SKILL.md`（builder は実装前に読む）

## 1. 題材・利用者・仕事
- 題材: 日本の文化史（仏像・絵巻・屏風・建築）。自分の**美術館**に作品を集めていく
- 利用者: 受験を控えた高校生（15〜18 歳）。通学の電車やベッドで、片手・縦持ち・3 分
- 仕事: 画像を見て即答し、解説を読み、また来る。**画像が主役**。UI は画像を邪魔しない

## 2. デザインプラン（トークン）
### 色 — 岩絵具（日本画の顔料）から取る。夜の展示室が基調
| 名前 | 役割 | 値 |
|---|---|---|
| 墨（sumi） | 背景（ダーク既定）。展示室の暗幕。画像が映える | `#15171C` |
| 墨・面（sumi-surface） | シート・ボタン面 | `#22252D` |
| 胡粉（gofun） | 文字・面（ライト時は背景） | `#F1EEE6` |
| 群青（gunjo） | 主アクション・選択中・進捗 | `#3A5BC7` |
| 金（kin） | 所蔵・習熟・正解の額縁。**唯一の華やかさ** | `#C9A24C` |
| 緑青（rokusho） | 正解の判定色 | `#4E9E88` |
| 朱（shu） | 不正解の判定色のみ。装飾に使わない | `#C8553B` |
- ライトモード（`prefers-color-scheme: light`）: 背景 胡粉 `#F1EEE6`、面 `#FFFFFF`、文字 墨 `#15171C`、他は同じ。既定はダーク（展示室）
- グラデーション・ぼかしの装飾は使わない。影は「浮いているもの」（シート、ドラッグ中）にだけ 1 種類

### 文字 — 「作品名は展示キャプション、UI はシステム」
- 表示用（作品名・文化名・数字の見出し）: **Shippori Mincho B1**（Google Fonts、`font-display: swap`、必要ウェイト 500/700 のみ）。美術館のキャプション板の明朝。作品名は縦長の画像の下に 22〜28px、行間 1.3、字間 0.02em
- UI 用（ボタン・本文・解説）: `system-ui, -apple-system, "Hiragino Sans", "Noto Sans JP", sans-serif`。iPhone のネイティブ感を出す。本文 16px／行間 1.7、解説の 1 行は 全角 35 字以内
- 型スケール: 13 / 15 / 17 / 22 / 28 / 40（読み仮名 13、本文 15〜17、作品名 22〜28、セッション結果の数字 40）
- やらないこと: 見出しの 1 語だけ色を変える／英大文字のラベル／中黒でつないだメタ情報／`→` を付けたボタン文言／本文の上に不要な小ラベル

### レイアウト — 画像を主役にした 1 列
```
学習（出題）                      解説シート（下から）
┌──────────────┐          ┌──────────────┐
│ 3/10  ●●●○○○ │ 細い進捗  │ ── ドラッグ手 ──│
│┌────────────┐│          │ ✓ 正解  +10    │ 判定は 1 行
││            ││          │ ┌──┐ 阿修羅像   │ 正解: 金の額縁
││   画  像   ││ 角丸16   │ │  │ あしゅらぞう │ 明朝
││ 画面幅いっぱい│          │ └──┘ 天平・興福寺│
││            ││          │ ・三面六臂 …    │ keyPoints
│└────────────┘│          │ 解説本文 …      │
│ この作品は？   │          │ ── 他の選択肢 ──│
│┌────────────┐│          │ ┌─┐ 十大弟子像  │ 小画像+1行
││ 阿修羅像     ││ 56px高   │ └─┘ 見分け方: …│
│├────────────┤│          │ …             │
││ 十大弟子像   ││          │ ⚠ 入試での注意 │
│├────────────┤│          │ [ 次の問題 ]   │ 群青・固定下
││ 執金剛神像   ││          └──────────────┘
│├────────────┤│
││ 鑑真和上像   ││
│└────────────┘│
└──────────────┘
```
- 左揃え。中央揃えはセッション結果の数字だけ
- 画像は画面幅いっぱい（左右 16px 余白）、3:4 か 4:3 を作品ごとに保ち `object-fit: contain`、背景は墨・面。角丸 16px。**画像だけが角丸を持つ**（ボタンは 12px、シートは上だけ 20px。角丸を階層の情報として使う）
- 選択肢は縦積み 4 段、高さ 56px、面色は墨・面、文字 17px。選択後: 正解＝金の 2px 枠＋緑青の✓、誤選択＝朱の枠。他は減光
- 解説シートは画面の 92% まで上がるボトムシート。ドラッグで閉じない（誤って閉じて解説を飛ばさせない）。「次の問題」だけが閉じる
- 図鑑: 3 列グリッド、サムネイルは 3:4。未発見＝墨・面の無地に薄い作品名だけ、発見＝画像、**所蔵＝金の細い額縁（`outline` 2px + `outline-offset` 3px）**。時代見出しは明朝＋「n / 総数 所蔵」
- ホーム: 上から「連続 n 日」（小さく）→ 今日の展示室（進行中の時代の名前を明朝で大きく、その下に所蔵率の細いバー）→ **「学習を始める」**（全幅 56px、群青。復習 n・新規 m を小さく添える）→ 次の時代ボスまでの残り。カードを並べない
- 下部タブ 4 つ（ホーム／学習／図鑑／成績）。アイコンは線画 24px、選択中は群青。`env(safe-area-inset-bottom)` 分を足す
- 動き: **1 か所だけ**。セッション終了時、新しく発見した作品が図鑑の枠に「掛かる」（下から 12px 上がって金枠が 1 回光る、0.6 秒）。それ以外は操作への応答のみ（シートのスライド、選択肢の枠の色）。`prefers-reduced-motion` で全部止める

### 原則（この画面を他と区別するもの）
1. 画像が主役。UI は暗幕。色は判定と所蔵にしか使わない
2. 「額縁」が進捗の言語。発見→所蔵を枠で表す。バッジ・星・紙吹雪は使わない
3. 明朝の作品名＝展示キャプション。UI 文言はシステムフォントで短く
4. 文言は動詞で。「学習を始める」「次の問題」「図鑑に追加した」「進捗を書き出す」。「送信」「OK」「がんばろう！」のような空文言は使わない
5. 空の状態は次の行動を示す（図鑑が空: 「最初の作品を見つけよう」＋学習を始めるボタン）

## 3. 見直し（既定の見た目になっていないか）
- 「クリーム背景＋明朝＋テラコッタ」に寄りやすい題材だが、**基調は暗い展示室・アクセントは群青・華やぎは金のみ**にして避けた。明朝は作品名だけに限定し、本文には使わない
- 「黒背景＋1 色の蛍光」にもしない。判定の緑青／朱、進捗の群青、所蔵の金と、色に役割がある
- カードキット（同じ角丸・同じ影のカード羅列）を避ける。ホームはカードを並べず 1 列の流れ。角丸は画像 16／ボタン 12／シート 20 と階層で変える
- 番号付きマーカー（01/02）は使わない（順序のある内容ではない）。進捗の「3/10」だけが数

## 4. 品質の床
- 320〜430px 幅で崩れない。片手の親指で届く位置に主アクション（画面下）
- キーボードフォーカスが見える（群青の 2px アウトライン）。コントラスト比 4.5:1 以上（胡粉 on 墨、墨 on 胡粉）
- `prefers-reduced-motion` 対応。画像に `alt`（作品名は出題中は伏せ、解説では表示）
- フォントは Shippori Mincho の 2 ウェイトのみ。初回ロード（画像除く）300KB 以内を維持
- 実装後、Chrome の iPhone エミュレーションでスクリーンショットを撮って自己批評し、1 つ装飾を削る
